# The-Ballad-of-Power-and-Fear

Scroll-based interactive website inspired by *The Ballad of Songbirds and Snakes*.

## Overview
This project uses visual storytelling and scroll-triggered animations to explore
themes of ambition, fear, choice, power, and transformation.

The website focuses on meaning and narrative flow rather than decoration.
Each section represents a stage in Coriolanus Snow’s development.

## Sections
- Ambition  
- Fear  
- Choice  
- Power  
- President Snow  
- Reflection  

## Built With
- HTML  
- CSS  
- JavaScript  


## Notes
This project was improved conceptually rather than rebuilt.
Animations and visuals are symbolic and intentional.
